# 土方歳三と乾杯！AR

スマートフォンのカメラで対象のビールラベルを映すと、画面上に土方歳三が現れて乾杯する WebAR コンテンツです。<br>
アプリのインストールは不要で、公開 URL をブラウザで開くだけで体験できます。

## 体験できること

- ビールラベルをカメラで映すと、土方歳三の乾杯動画が表示されます
- 登場時に煙、金色の光、影、短いセリフが重なって表示されます
- ラベルが画面から外れると演出はいったん消え、もう一度映すと再表示されます

## 利用に必要なもの

- カメラ付きスマートフォン
- インターネット接続
- 対象のビールラベル、またはラベルを印刷した紙
- HTTPS で公開されたこの AR ページの URL

## 推奨環境

- iPhone: Safari
- Android: Chrome

カメラを使うため、通常の公開 URL では HTTPS が必要です。<br>
うまく動かない場合は、まず推奨ブラウザで開き直してください。

## 使い方

1. スマートフォンで AR ページの URL を開きます
2. 表示された案内画面で「ARを開始」を押します
3. ブラウザからカメラ権限を求められたら許可します
4. 明るい場所で、対象のビールラベルを画面内に入れます
5. ラベルが認識されると、土方歳三が表示されて乾杯演出が始まります

## きれいに表示するコツ

- ラベル全体が画面に入るように映してください
- なるべく明るい場所で試してください
- ラベルに光が強く反射しない角度にしてください
- 最初は缶や瓶に貼られた曲面ラベルではなく、紙に印刷したラベルで試すと認識しやすいです
- カメラを近づけすぎず、ラベルがぼやけない距離にしてください

## 困ったとき

### 「ARを開始」を押してもカメラが起動しない

- ページを HTTPS の URL で開いているか確認してください
- ブラウザのカメラ権限が許可されているか確認してください
- iPhone は Safari、Android は Chrome で開き直してください
- ページを再読み込みして、もう一度「ARを開始」を押してください
- 他のアプリがカメラを使用している場合は終了してください

### ラベルを映しても土方歳三が表示されない

- ラベル全体が画面内に入っているか確認してください
- ラベルを正面に近い角度で映してください
- 暗い場所や強い反射がある場所を避けてください
- ラベルが折れている、汚れている、ぼやけている場合は認識しづらくなります
- 印刷したラベルで試す場合は、できるだけ鮮明に印刷してください

### 途中で表示が消える

ラベルを見失うと演出は自動的に消えます。<br>
もう一度ラベル全体を画面内に入れると、再び表示されます。

## パソコンで表示確認だけ行う場合

パソコンでページの見た目を確認する場合は、ファイルを直接開かず、ローカルサーバーで起動してください。

```bash
python -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` を開きます。<br>
ただし、実際の AR 体験やカメラ確認はスマートフォンの HTTPS 環境で行ってください。

## 公開する場合

このプロジェクトは静的ファイルだけで動作するため、GitHub Pages などに配置して公開できます。

1. リポジトリを GitHub に push します
2. GitHub の **Settings > Pages** を開きます
3. 公開するブランチとフォルダを選びます
4. 発行された HTTPS の URL をスマートフォンで開きます

## 注意事項

- カメラ利用には HTTPS が必要です
- 初回表示時はライブラリや動画素材を読み込むため、通信環境によって少し時間がかかる場合があります
- 屋外や店頭などで使う場合は、周囲の安全を確認してから体験してください
- 商用利用やイベント利用の前に、ラベル、ブランド、動画、画像素材などの権利を確認してください
